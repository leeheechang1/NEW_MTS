# NEW_MTS

모바일 MTS UI 프로토타입이 추가되었습니다.

## 포함된 파일

- `index.html` - 모바일 MTS 화면 구조
- `styles.css` - 카카오페이증권 스타일 UI 및 모바일 레이아웃
- `script.js` - 탭 전환 및 간단한 실시간 호가 데이터 토글

## 실행 방법

1. `index.html` 파일을 브라우저에서 열기
2. 또는 간단한 웹서버에서 실행:

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속
